== Description ==

A WordPress plugin for construction companies, general contractors, and project managers. Manages project milestones, subcontractor punch lists, OSHA safety incident reporting, equipment inspection logs, and permit tracking. Features client-facing project progress portals, daily log submissions from mobile, and automated weekly status report generation. Built for firms needing a lightweight alternative to expensive construction management software.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Construction Project Management and Safety Compliance WordPress Plugin
